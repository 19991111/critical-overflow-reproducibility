# 有限 q 验证与 v4 结果

这批数据支持预先规定的有限规模精度目标。它没有验证非零耦合 SDE 的完整边际分布，也不能代替渐近证明。

在 q=512 时，16相位反馈误差的轨迹 RMS 超过0.10的概率，同时上界均为0.007；5点溢出窗口的最大误差超过0.05的概率，同时上界为0.058、0.058、0.059、0.064、0.073、0.070。预定目标都是失败概率不超过0.10。溢出失败并非零：确定失败数37至49；数值包络边界内的可能失败数至50，全部保留。10格同时置信覆盖至少97.5%，前提是声明的理想独立流模型。

匹配核与乘积核的最大规模终态CDF比较，在λ=1、2的归一化失衡和溢出上，观测KS分别9/1024、17/1024、13/1024、1/64。DKW同时成对半宽0.114；真实CDF距离上界0.122790、0.130602、0.126696、0.129625，均低于冻结0.20容差。该组同时覆盖至少97.5%，与主检验合计错误预算不超过0.05。下界为0，不建立正分离。这里的“支持”指区间整体进入预定范围；不能写成“未拒绝所以等价”或“两个分布完全相同”。

λ=0的理论极限为布朗失衡；确定性正态积分将均值E S0(B1)包住于[0.7461095327556870,0.7506173290447714]。q512均值0.747039794921875，MCSE0.004703203662256；含参考数值误差的名义3MCSE差值区间约[-0.017688,0.015040]。这是诊断，不附严格统计覆盖保证。没有新的SDE Monte Carlo样本。

实际参数、种子、阈值、算法、预算在执行前冻结。q=64/128/256/512，每λ的重复数128/128/256/1024，λ=0/1/2，κ=1；固定identity matching和product；共4608对、9216份轨迹，全部完成。16反馈时刻使用真实共同相位，对照g(h,d)，没有误用相位平均gbar；溢出保留整数容量相位。确定性轮廓查表误差上界0.00004861（反馈）和0.00002440（溢出）均进入判定。种子标签间的伪随机流可复现，但不等于证明机器流独立；严格频率覆盖条件必须保留。

最大规模固定核平均反馈RMS约0.026，乘积核约0.014；固定匹配到乘积响应的成分约0.022，仍有可见有限规模配对效应。平均溢出最大误差约0.027。四规模误差均值在这批数据下降，但没有拟合收敛率；各格临界均值不全随规模单调。小规模全部是描述性数据，未事后升级为主检验。

模型墙钟22.352秒，总计算28.427秒，均在预定预算内。CPU360秒/墙钟420秒、分析120秒/总600秒、1线程、1GiB为限额；实际CPU秒和峰值RSS没有单独记录。该耗时不是算法性能比较。核验与排版在批次结束后进行；没有并发计时对照干扰。

全部9216完整临界配置独立重读通过。进一步从193536个原始检查点重建四侧直方图质量、社区质量、溢出、乘积反馈整数计数、固定联合表边缘及全部9216份指标，最大舍入差2.221e-16，低于审计容差5e-14。λ=0的32256个配对检查点一致。新增审计只读取冻结数据，不生成轨迹。

v4全文以固定核临界等价性、唯一均值锁定格点周期轮廓、均匀重启闭合、平滑临界扩散及保留端点相位的溢出曲线为主线。文中包含证明、数值证书、实际有限q结果、五篇重点相关工作的逐项边界，以及Stolyar3.1/3.2条件纠正。数值轮廓误差证书约9.0331e-6；这是流体轮廓误差，不是有限q误差。

剩余限制：非零λ扩散边际没有验证；κ仅为1；只实验identity matching和product，没有扫所有固定双随机矩阵；没有有效轮廓吸引率、稳态交换或其他tie规则结论。本环境没有第二种CPU；真实键与字典实现的旧阻塞不由这批抽象分配实验解决。旧证书失败、旧CDF失败、v3及原始日志保持原状。
