# 前瞻冻结的新微观确认批次

执行能力已经恢复，本次唯一新批次已实际完成；并非仅受理指令。固定 q=512、κ=1、λ∈{1,2}，对匹配核与乘积核各使用 4096 个新重复标签，共 8192 对、16384 条微观终态。复用旧 SDE 参考，新增 SDE 轨迹为零。

四项无条件均值比较与四项完整终态 CDF 比较均支持预先冻结的实用容差：均值差 ±0.05，CDF 距离 0.20。没有不一致或不确定判定。全部计算及独立核验共 48.29 CPU 秒、48.42 秒墙钟，单核单线程，未补种、重跑或调整门槛。

这是对上述四个固定微观配置的新数据确认。联合覆盖率至少 95% 以输入字在每条流内部及重复标签之间均独立均匀、且新微观输入独立于旧历史，以及既有参考数值误差合同为条件；不是对确定性 PRNG 独立性的认证。旧参考被重复使用，不能把它算作又一次独立参考实验。本次条件联合保证不恢复旧事后微观均值的选择校正保证。

阅读 [实验报告](EXPERIMENT_REPORT.zh.md)、[事前统计计划](STATISTICAL_PLAN.en.md)、[实现与来源核对](IMPLEMENTATION_REVIEW.en.md)。精确结果在 results/MEAN_COMPARISONS.json、results/CDF_COMPARISONS.json；独立核验见 results/INDEPENDENT_CHECK.json，全部命令、环境、计时和标准输出保存在 protocol/ 与 logs/。

新增内容仅在本目录。论文原稿、旧结果、314 个旧文件及 40 个先前归档保持原字节；main、华为线、S07、其他分支不改。本任务没有新增物理 CPU 验证、性能基准、云资源、付费承诺、外部数据授权、监督器或自动化。

原始终态配置共八个二进制分片；布局为七字节 PMCFG1\0 标识，随后每条小端记录 `<IIIIQ1024I`：q、λ、重复标签、核、到达数、1024 个有标签的整数负载。每条记录与 outcomes.csv 精确对应，progress.csv 保留每一对的完成记录与输入摘要。完整输入字由冻结种子和计数器函数可重建。禁止覆盖本批次重现；需要重现时使用另一个明确标识的空目录，按冻结命令编译并执行。

归档为 micro_prospective_return.tar.gz，成员清单及 SHA256 在 RETURN_MANIFEST.json；最终接收凭据在 DELIVERY_RECEIPT.json，独立网络克隆回读在 REMOTE_READBACK.json。归档不包含自身、成员清单及随后生成的交付元数据，以避免递归和提交自引用。
