# Implementation and provenance check

The immutable source is research/paper_v4_release_20261017/src/finite_q.cpp. New src/micro.cpp keeps its exact counter word function and state update: global-left tie, integer increment, community mass, and spill increment when the previous winning load is at least c. At q512 its old bits=9 and mbits=8 are explicit constants; low nine bits choose cross type (<lambda), next bit chooses the left community; low eight bits of the second word choose i and the next eight choose j. Internal edges always use j; identity cross edges use i; product cross edges use j. The FNV-style two-word driver digest and initial state are identical recipes.

The authorized new experiment stops exactly at n*=q^2. It does not rerun the old multi-scale, lambda0, postcritical-window or wave-feedback study. It drops wave/profile diagnostics and computes only the new prespecified integer endpoints and complete labelled configurations. This reduces computation without changing the target n* process. There are no new wave tables or SDE trajectories. Deterministic small exhaustive edge-law, capped-coupling, tie and mass/spill tests use no random words. Runtime terminal identities and an independently written complete-configuration parser check all produced records.

Source freeze includes the statistical plan, design, seeds, input locks, alpha arithmetic, environment, duplicate guard, source implementation, analyzer and independent verifier before fresh trajectories. The later seal/network scripts and report are delivery code, not retroactive additions to the statistical recipe. Release source and final output freezes cover those later additions separately. The complete old/new source diff is saved in SOURCE_CHANGES.diff for inspection; it is not claimed to have been a separate preregistration.

The reference interval endpoints, approximation constants and CDF bands are reused from their own original fixed recipes. New code verifies the exact frozen reference inputs, parses stored long-double hexadecimal data into exact rationals, and never reads old micro outcome rows to estimate a new micro mean or CDF. Old micro and reference seed files are read only for collision checks. Old micro outcomes remain in the preservation lock, not in new estimators.

Mean and CDF methods are chosen prospectively for the fresh micro sample. Their proof is fixed-time, conditional on new ideal iid words given the entire old history. The reference confidence events are old valid events with their original alpha costs; this new family's guarantee is unconditional over reference and fresh micro. No selection-uniform statement is added to the old micro mean analysis. The source keeps raw values even when clipping for inference. All endpoint products and jump suprema are exact; directed tail bounds round upwards.

The read-only independent verifier uses sequential math.prod instead of the analyzer's grouped balanced product, and bisect_right over all jumps instead of its simultaneous CDF sweep. It validates endpoints and their neighboring grid points, tail allowances, mean subtraction and the final prespecified decisions. This provides implementation cross-checks, not a second proof of the ideal input model or a second random experiment.
