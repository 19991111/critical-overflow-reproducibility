## 独立核验和预算

参考数据完整后先冻结，再执行只读核验：参考4个统计端点及相邻网格共8组以50位定向Decimal逐项求和核验；微观端点及邻格16组以直接大整数乘积复核；4个全域平移CDF界用独立二分秩计数算法复算。全部通过，没有生成任何新轨迹。

固定算术校准给出带1.5系数的主循环预测116.58CPU秒，实际参考采样160.39CPU秒，高于预测；该预测不作为硬上界。包含导表、编译、自检、校准、采样的参考总CPU为166.13秒，低于600秒硬限额。主流水线墙钟171.76秒，只读独立核验25.14秒，计算阶段合计196.91秒，低于1200秒整体预算。全程固定单核0、内存上限1GiB；没有新增云资源、权限、付费承诺或监督器。

范围限制仍然明确：仅检查T=1终态D的全域CDF容差和无条件溢出均值；没有多时刻／路径分布、其他κ、其他λ或其他固定矩阵结果，也没有有限q收敛率证明。底层轮廓及Euler误差界是内部数学推导与数值核验，非机器形式化或外部同行审查。严格概率覆盖仍以理想独立重复流及所写数值算术条件为前提。
